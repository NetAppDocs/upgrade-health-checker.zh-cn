= 通过电子邮件接收升级运行状况检查器报告
:hardbreaks:
:allow-uri-read: 
:icons: font
:linkattrs: 
:imagesdir: ./media/


[role="lead"]
升级运行状况检查器可以将报告直接通过电子邮件发送到您的收件箱。通过 config.yaml 文件或命令行参数启用此功能。启用后，升级运行状况检查器将生成的报告（HTML、Excel 或 JSON）通过 SMTP 服务器发送到一个或多个收件人。禁用时，不会发送报告。如果报告生成失败并启用电子邮件，则升级运行状况检查器会将日志文件通过电子邮件发送给配置的收件人。



[[configure-using-the-config-yaml-file]]
== 使用 config.yaml 文件进行配置

可以通过启用电子邮件报告、添加 SMTP 服务器详细信息以及指定收件人地址和报告格式，在 config.yaml 文件中配置电子邮件设置。

. 在 config.yaml 文件中启用电子邮件报告。
+
[listing]
----
# Email Report Configuration
EMAIL:
  ENABLED: true
----
. 添加 SMTP 配置设置、发件人详细信息和主题：
+
[listing]
----
# SMTP Server Configuration
EMAIL:
  ENABLED: true
  FROM: "uhc-notify@example.com"
  SUBJECT: "UHC Upgrade Health Report"
  REPLY_TO: <email>
  SMTP:
    HOST: "smtp.example.com"
    PORT: [<port-number>]
----
. 添加收件人电子邮件地址，并设置系统通过电子邮件发送的报告格式，例如 HTML、EXCEL、JSON 或 ALL。您还可以使用身份验证和加密：
+
[listing]
----
# Recipient Email Addresses, report formats
EMAIL:
  ENABLED: true
  TO: <recipient>
  FROM: "uhc-notify@example.com"
  SUBJECT: "UHC Upgrade Health Report"
  REPLY_TO: <email>
  RECIPIENTS: "user1@example.com, user2@example.com"
  REPORT_FORMATS: "HTML,EXCEL,JSON"   # valid values: HTML, EXCEL, JSON or ALL
  SMTP:
    HOST: "smtp.example.com"
    PORT: [PORT]
    USE_SMTP_AUTH: true
    USE_TLS: true
    USE_SSL: true
    USERNAME: "user@example.com"
    PASSWORD: "********"
----




[[configure-using-command-line-arguments]]
== 使用命令行参数配置

您可以使用命令行参数配置基本电子邮件设置，以启用报告、指定收件人和选择报告格式。

. 使用命令行参数启用电子邮件报告：
+
[listing]
----
./uhc --email-enabled=true
----
. 提供收件人电子邮件地址：
+
[listing]
----
./uhc --email-recipients="user1@example.com, user2@example.com"
----
. 配置通过电子邮件发送的报告格式，例如 HTML、EXCEL、JSON：
+
[listing]
----
./uhc --email-report-formats=HTML,EXCEL,JSON
----


[NOTE]
====
您可以使用命令行参数或 config.yaml 文件配置以下三个属性。您只能在 config.yaml 文件中配置所有其余属性：

* 电子邮件已启用
* 电子邮件收件人
* 电子邮件报告格式


请注意，命令行参数会覆盖 config.yaml 文件中的值。

例如：

[listing]
----
./uhc \
  --email-enabled=true
  --email-recipients="user1@example.com, user2@example.com" \
  --email-report-formats=HTML,EXCEL,JSON \
----
[listing]
----
EMAIL:
  FROM: "uhc-notify@example.com"
  SUBJECT: "UHC Upgrade Health Report"
  REPLY_TO: <email>
  SMTP:
    HOST: "smtp.example.com"
    PORT: [PORT]
----
====
